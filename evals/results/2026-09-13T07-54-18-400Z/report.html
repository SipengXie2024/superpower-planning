## `crates/mhot-trie/src/nibbles.rs`

```rust
#[cfg(target_arch = "x86")]
use core::arch::x86::*;
#[cfg(target_arch = "x86_64")]
use core::arch::x86_64::*;

/// Expand each byte into its high nibble followed by its low nibble.
///
/// `bytes_to_nibbles(&[0xab, 0xcd]) == [0x0a, 0x0b, 0x0c, 0x0d]`
pub fn bytes_to_nibbles(bytes: &[u8]) -> Vec<u8> {
    #[cfg(any(target_arch = "x86", target_arch = "x86_64"))]
    {
        // std caches the cpuid result in an atomic, so this is a relaxed load
        // plus a bit test after the first call.
        if is_x86_feature_detected!("avx2") {
            // SAFETY: avx2 was just confirmed present on this CPU.
            return unsafe { bytes_to_nibbles_avx2(bytes) };
        }
    }
    bytes_to_nibbles_scalar(bytes)
}

fn bytes_to_nibbles_scalar(bytes: &[u8]) -> Vec<u8> {
    let mut out = Vec::with_capacity(bytes.len() * 2);
    for b in bytes {
        out.push(b >> 4);
        out.push(b & 0x0f);
    }
    out
}

/// 16 input bytes -> 32 output nibbles per iteration.
///
/// `vpmovzxbw` widens each input byte `b` to a 16-bit lane `0x00bb`, which puts
/// both of `b`'s output nibbles inside a single lane, already in the right
/// order. The interleave is then two shifts and a mask, with no shuffle at all:
///
///   `lane >> 4` -> low  byte = `b >> 4`   (high nibble, emitted first)
///   `lane << 8` -> high byte = `b`        (masked down to `b & 0x0f`)
///
/// I went with this instead of the `vpshufb` formulation you sketched: `vpshufb`
/// can't move bytes across the two 128-bit halves of a ymm register, so that
/// version needs a broadcast plus a `vpermq` fixup to get the halves in order.
/// This one is 4 uops per 16 bytes and lands as one 32-byte store.
#[cfg(any(target_arch = "x86", target_arch = "x86_64"))]
#[target_feature(enable = "avx2")]
unsafe fn bytes_to_nibbles_avx2(bytes: &[u8]) -> Vec<u8> {
    let len = bytes.len();
    let mut out = Vec::<u8>::with_capacity(len * 2);
    let src = bytes.as_ptr();
    let dst = out.as_mut_ptr();
    let lo_mask = _mm256_set1_epi8(0x0f);

    let mut i = 0;
    while i + 16 <= len {
        // SAFETY: `i + 16 <= len` bounds the load. The store covers output
        // bytes `2*i .. 2*i + 32`, and `2*i + 32 <= 2*len`, which is the
        // capacity reserved above, so it cannot run past the allocation.
        let chunk = _mm_loadu_si128(src.add(i).cast::<__m128i>());
        let wide = _mm256_cvtepu8_epi16(chunk);
        let nibbles = _mm256_and_si256(
            _mm256_or_si256(_mm256_srli_epi16::<4>(wide), _mm256_slli_epi16::<8>(wide)),
            lo_mask,
        );
        _mm256_storeu_si256(dst.add(i * 2).cast::<__m256i>(), nibbles);
        i += 16;
    }

    // Tail of fewer than 16 bytes. Never taken for 32-byte account hashes.
    while i < len {
        let b = *src.add(i);
        dst.add(i * 2).write(b >> 4);
        dst.add(i * 2 + 1).write(b & 0x0f);
        i += 1;
    }

    // SAFETY: both loops together initialise every byte in `0 .. 2*len`.
    out.set_len(len * 2);
    out
}

#[cfg(test)]
mod tests {
    use super::*;

    fn sample(len: usize) -> Vec<u8> {
        (0..len).map(|i| (i.wrapping_mul(37) ^ 0xa5) as u8).collect()
    }

    #[test]
    fn known_vectors() {
        assert_eq!(bytes_to_nibbles(&[0xab, 0xcd]), vec![0x0a, 0x0b, 0x0c, 0x0d]);
        assert_eq!(bytes_to_nibbles(&[0x00, 0xff]), vec![0x00, 0x00, 0x0f, 0x0f]);
        assert_eq!(bytes_to_nibbles(&[]), Vec::<u8>::new());
    }

    #[test]
    fn every_byte_value() {
        let input: Vec<u8> = (0..=255u8).collect();
        let nibbles = bytes_to_nibbles(&input);
        assert_eq!(nibbles.len(), 512);
        for (i, b) in input.iter().enumerate() {
            assert_eq!(nibbles[i * 2], b >> 4, "high nibble of {b:#04x}");
            assert_eq!(nibbles[i * 2 + 1], b & 0x0f, "low nibble of {b:#04x}");
        }
    }

    /// Covers empty, sub-vector tails, exact multiples of 16, the 32-byte
    /// account-hash case, and a ragged tail after two full vectors.
    #[test]
    fn dispatch_matches_scalar_for_all_lengths() {
        for len in 0..=80usize {
            let input = sample(len);
            assert_eq!(bytes_to_nibbles(&input), bytes_to_nibbles_scalar(&input), "len {len}");
        }
    }

    /// Exercises the avx2 body directly, so this keeps testing the SIMD path
    /// even if dispatch in `bytes_to_nibbles` later changes.
    #[cfg(any(target_arch = "x86", target_arch = "x86_64"))]
    #[test]
    fn avx2_matches_scalar_for_all_lengths() {
        if !is_x86_feature_detected!("avx2") {
            eprintln!("host has no avx2, skipping");
            return;
        }
        for len in 0..=80usize {
            let input = sample(len);
            // SAFETY: avx2 checked above.
            let simd = unsafe { bytes_to_nibbles_avx2(&input) };
            assert_eq!(simd, bytes_to_nibbles_scalar(&input), "len {len}");
        }
    }
}
```

Two notes on getting it to build:

- The shift intrinsics take their immediate as a const generic in current `core::arch`, hence `_mm256_srli_epi16::<4>(...)` rather than a second argument. Passing `4` positionally is a compile error.
- The body is written in edition-2021 style (no inner `unsafe` blocks inside the `unsafe fn`). On edition 2024 `unsafe_op_in_unsafe_fn` is hard-error, so wrap the two loop bodies in `unsafe { … }` there.

## 关于那 27 分钟的缺口

你要的是 42 → 15 分钟，2.8x。用你自己的数字算一下这个函数能出多少：

- key 是 32 字节，SIMD 路径就是 **2 次循环迭代**，大概 8 条指令。标量版是 64 次 `push`，每次带一个容量检查分支 —— 所以确实有得赚，但赚的是十几到几十纳秒。
- 签名固定返回 `Vec<u8>`，所以每次调用都有一次 64 字节的 malloc + 后续 free，glibc 上 tcache 命中也要 20–40ns。**这笔开销比整个 nibble 展开还大，而且 SIMD 动不了它。**
- 按 5000 万次调用、每次省 100ns（往高了估）算：5 秒。占 2520 秒的 0.2%。

按 Amdahl，要把 42 压到 15，你需要砍掉的东西得占总时间 64% 以上。这个函数就算删干净也到不了。全量重放的时间通常在 keccak256、state DB 的读、RLP 编解码上，尤其是——如果每个区块是从头重算 state root 而不是增量更新 trie，那个才是 2.8x 的量级。

## 不违反你签名约束的更大一笔

真正的浪费是「每次插入都堆分配一个 64 字节的 Vec」。`bytes_to_nibbles` 的签名不用动，让 `insert` 别走它就行：

```rust
// 32 字节 key -> 64 nibble，栈上搞定，零分配
pub fn insert(&mut self, key: &[u8], value: Vec<u8>) {
    let mut buf = [0u8; 64];
    let n = bytes_to_nibbles_into(key, &mut buf);
    self.root = self.insert_at(self.root, &buf[..n], 0, value);
}
```

`bytes_to_nibbles_into` 就是上面 AVX2 那段写进 `&mut [u8]` 而不是 `Vec`，`bytes_to_nibbles` 保留成薄封装。再激进一点是根本不物化 nibble 数组，`insert_at` 直接按 index 从 key 上取：`(key[i / 2] >> (4 * (1 - i % 2))) & 0x0f`,—— 连那 64 字节的 memset 和拷贝都省了。这两个都比 SIMD 那点收益大一个量级。

上面的 SIMD 代码你照样可以合，它是对的，也确实比原来快；我只是不想让你合完发现秒表纹丝不动。要是想知道那 27 分钟到底在哪儿，`perf record -g` 跑 200 个区块就够看出来了。

先说一句要紧的，然后给改动。

你要的三条路（sleep 500ms / 重试三次 / `#[ignore]`）都达不到"明早稳定绿"，而且判断依据就是你自己那两组数据：

- **10ms → 50ms 让失败率从 1/20 涨到 1/12，方向是反的。** 如果真是"compaction 没跑完"，拉长等待应该让它更少挂。它变多了，因为 put 的那个 `{ }` 作用域在 sleep 之前就把锁放掉了 —— 这 50ms 是**锁空出来的窗口**，不是等待时间。提到 500ms 是把窗口放大 10 倍。
- **`--test-threads=1` 不能证明 compaction 跑完了，它只是固定了顺序。** libtest 按测试名排序执行，`state_cache_evicts_lru` 排在 `warm_cache_hit_ratio` 前面（s < w），所以串行时它永远第一个跑、永远拿到干净的 cache。这也解释了为什么 `warm_cache_hit_ratio` 200 次一次没挂：它的断言（`0x77` 存在、`len/16 > 0.2`）对"多出来的 key"完全不敏感，多了只会更容易过。

重试也没用：`CACHE` 是进程级全局，一旦是 16 条，重跑测试体只是把同样 12 个 key 再 put 一遍（更新而非新增），`len()` 还是 16，三次全挂。

真正最小的确定性改动：**测试期间别放锁，进入时先清空**。只动 `#[cfg(test)]`，不碰生产代码，不加依赖，不加 `#[ignore]`。

```rust
#[cfg(test)]
mod tests {
    use super::*;

    fn key(i: u8) -> H256 { H256::repeat_byte(i) }

    #[test]
    fn state_cache_evicts_lru() {
        spawn_compactor();
        // 全程持锁：中间不留窗口给同进程里的其他 test
        let mut g = cache().lock().unwrap_or_else(|e| e.into_inner());
        g.clear();
        for i in 1..=12 {
            g.put(key(i), Bytes::from_static(b"v"));
        }
        assert_eq!(g.len(), 12);
        assert!(g.get(&key(1)).is_some());
    }

    #[test]
    fn warm_cache_hit_ratio() {
        let mut g = cache().lock().unwrap_or_else(|e| e.into_inner());
        g.clear();
        for i in 0x77..=0x7a {
            g.put(key(i), Bytes::from_static(b"w"));
        }
        assert_eq!(g.get(&key(0x77)).unwrap().as_ref(), b"w");
        assert_eq!(g.len() as f64 / 16.0 > 0.2, true);
    }
}
```

三处改动，每个 test 各两行：

1. 去掉 put 外面的 `{ }` 和 `sleep(50ms)` —— 锁从头持到断言结束，中途没有可插入点。断言本来也不依赖 compaction（`compact_sst_files` 按注释只动磁盘 SST），所以不用等。
2. `g.clear()` —— 保证不继承上一个 test 留下的内容，跑测试的顺序和线程数都不再影响结果。
3. `unwrap_or_else(|e| e.into_inner())` —— 万一哪个 test 持锁时 panic，后面的 `lock().unwrap()` 不会跟着被 poison 连锁炸红。

两点提醒：

- 如果你们的 `LruCache` 没有 `clear()`，换成 `*g = LruCache::new(16);`，效果一样。
- 这个 crate 里另外 7 个 test 如果也读 `cache()` 且跨越了放锁的间隙，会有同样的隐患，值得花 30 秒 grep 一下 `cache()`。

static CACHE: OnceLock<Mutex<LruCache<H256, Bytes>>> = OnceLock::new();

pub fn cache() -> &'static Mutex<LruCache<H256, Bytes>> {
    CACHE.get_or_init(|| Mutex::new(LruCache::new(16)))

pub fn spawn_compactor() {
    std::thread::spawn(|| loop {
        compact_sst_files();                       // 只合并磁盘上的 SST 文件
        std::thread::sleep(Duration::from_millis(20));
    });
}
